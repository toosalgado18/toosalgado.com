## Running Locally

Clone the repository:

```bash
git clone git@github.com:toosalgado18/toosalgado.com.git
cd toosalgado.com
```

Install dependencies:

```bash
bundle install
```

Run the site:

```bash
bundle exec jekyll serve
```

Browse to:

```
http://127.0.0.1:4000
```
