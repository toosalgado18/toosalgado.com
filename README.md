# 🚀 Running Locally

Clone the repository:

```bash
git clone git@github.com:toosalgado18/toosalgado.com.git
cd toosalgado.com
```

Install dependencies:

```bash
bundle install
```

Start the local server:

```bash
bundle exec jekyll serve
```

The site will be available at:

```
http://127.0.0.1:4000
```
